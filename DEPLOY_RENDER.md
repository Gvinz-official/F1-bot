# Бесплатный деплой: Render (бот) + Neon (база данных)

Карта не нужна. Бот живёт на Render, данные (монеты, ставки, друзья) хранятся в бесплатной базе Neon, поэтому не пропадают при перезапусках.

**Перед началом:** остановите бота и туннель на своём компьютере (два бота одновременно конфликтуют).

## 1. База данных Neon

1. Откройте neon.com и зарегистрируйтесь (через Google или GitHub, карта не нужна).
2. Create project: имя `f1bot`, регион **AWS Europe (Frankfurt)**.
3. На странице проекта нажмите **Connect**, включите **Connection pooling** и скопируйте строку вида:
   `postgresql://пользователь:пароль@ep-...-pooler....neon.tech/neondb?sslmode=require`
   Сохраните её, это ваш `DATABASE_URL`. Никому её не показывайте.

## 2. Код на GitHub

1. Зарегистрируйтесь на github.com, создайте **приватный** репозиторий `f1bot` (без README).
2. В терминале, в папке `f1bot`:
   ```
   sudo dnf install git gh
   gh auth login
   git init
   git add .
   git commit -m "F1 bot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/f1bot.git
   git push -u origin main
   ```
   Файл `.env` в репозиторий не попадёт (он в `.gitignore`), токен остаётся только у вас.
   Без терминала: на странице репозитория Add file → Upload files, перетащите содержимое папки `f1bot`, кроме `.venv`, `.env`, `data`.

## 3. Render

1. render.com → Sign up через GitHub.
2. **New + → Blueprint**, выберите репозиторий `f1bot`. Render прочитает `render.yaml`.
3. Заполните две переменные: `BOT_TOKEN` (токен от BotFather) и `DATABASE_URL` (строка из Neon). Нажмите **Apply**.
4. Дождитесь сборки (несколько минут). В **Logs** должна появиться строка «Мини-приложение слушает».

## 4. Проверка

- Откройте `https://ИМЯ.onrender.com/healthz` (адрес показан в панели Render), должно быть `{"ok": true}`.
- В Telegram: `/start`, затем «Открыть приложение».
- Если кнопки приложения нет, в Render → Environment добавьте `WEBAPP_URL` = ваш адрес `https://ИМЯ.onrender.com` и перезапустите.

## 5. Чтобы сервис не засыпал

Бесплатный сервис Render засыпает после 15 минут без входящих запросов. Бот раз в 10 минут сам обращается к своему адресу (самопинг включается автоматически на Render). Для надёжности добавьте внешний пинг: на cron-job.org создайте задачу GET `https://ИМЯ.onrender.com/healthz` каждые 10 минут. Он разбудит сервис, если тот всё же заснёт.

## Важно знать

- Render может перезапустить бесплатный сервис в любой момент. Данные не потеряются, они в Neon, а бот поднимется сам.
- Во время обновления кода на минуту могут появиться ошибки `Conflict: terminated by other getUpdates request`: так перекрываются старая и новая копии. Проходит само.
- Neon на бесплатном тарифе засыпает через 5 минут без запросов, первый запрос после паузы идёт чуть дольше. Лимит 100 CU-часов в месяц: бот специально обращается к базе редко, чтобы она успевала засыпать.
- Самопинг и внешний пинг это обходной путь: перечитайте условия Render, они могут измениться.
