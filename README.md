# F1 Tracker: бот + мини-приложение

Бот на aiogram 3 и Telegram Mini App в одном процессе. Данные берутся из Jolpica (Ergast) API.

## Что умеет

**Бот:** `/start /app /menu /next /results /standings /constructors /driver /lang /notify /help /about`, два языка (RU/EN), напоминания.

**Мини-приложение:**
- Гонка: светофор, обратный отсчёт, расписание уикенда, подиум последней гонки
- Календарь сезона с временем сессий в вашем часовом поясе
- Зачёт пилотов и команд, карточки с карьерой (титулы, победы, сезоны)
- Игры на **виртуальные монеты**: ставки (победитель, подиум, поул), дуэли напарников, тест реакции «Огни погасли», ежедневный бонус с серией
- Рейтинги (все / друзья, по монетам и по реакции), приглашение друзей по ссылке
- Напоминания в бот за час и на старте квалификации и гонки, автоматический расчёт ставок после гонки

Реальных денег, платежей и вывода средств нет, и добавлять их не стоит.

## Запуск (Windows, PowerShell)

1. Установите зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и вставьте `BOT_TOKEN`.
3. Мини-приложению нужен публичный HTTPS-адрес. Для теста поднимите туннель к порту 8080 (в отдельном окне):
   ```
   winget install Cloudflare.cloudflared
   cloudflared tunnel --url http://localhost:8080
   ```
   Он напечатает адрес вида `https://что-то.trycloudflare.com`. Вставьте его в `.env` как `WEBAPP_URL`.
   (Альтернатива: `ngrok http 8080`.)
4. Запустите бота: `python -m bot.main`
5. В Telegram отправьте боту `/start` и нажмите «Открыть приложение» (или кнопку меню слева от поля ввода).

Адрес быстрого туннеля меняется при каждом запуске: обновите `WEBAPP_URL` и перезапустите бота. Кнопка меню настраивается автоматически.

## Проверка без Telegram

В `.env` поставьте `DEV_MODE=1`, откройте `http://localhost:8080` в браузере. Без Telegram приложение входит как тестовый пользователь (другого можно задать заголовком `X-Dev-User`). В продакшене держите `DEV_MODE=0`.

## Тесты

`python -m tests.test_backend`: проверяет подпись Telegram, API, ставки и их расчёт, игру на реакцию, рейтинги и уведомления на поддельных данных F1.

## Структура

```
bot/main.py            запуск: бот + веб-сервер + планировщик
bot/handlers/          команды бота
bot/web/               API мини-приложения и проверка подписи Telegram
bot/services/          F1 API, игровая логика (коэффициенты, расчёт), уведомления
bot/db.py              SQLite (data/f1bot.sqlite3)
bot/i18n.py            тексты бота RU/EN
webapp/                интерфейс мини-приложения (index.html, style.css, app.js)
```
